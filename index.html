창업도 · 프랜차이즈 본사 전용

브랜드 페이지를
본사가 직접 관리하세요

회원가입부터 브랜드관리자 승인까지, 영업일 기준 1~2일이면 충분합니다. 브랜드 소개와 프로모션을 직접 게재해 보세요.

신청 방법 보기 멤버십 안내
STEP 1

회원가입하기

[기업회원]으로 가입

휴대폰 인증으로 간편하게 가입할 수 있습니다.

STEP 2

브랜드관리자 신청하기

CASE 1

창업도에서 [내 브랜드]가 검색되는 경우

  1. 로그인 (또는 기업회원 가입 후 로그인)
  2. 메인 페이지에서 [내 브랜드] 검색
  3. 브랜드 상세 페이지에서 [브랜드관리 바로가기] 클릭
  4. 브랜드관리자 신청 폼 작성
  5. 창업도에서 서류 확인 후 ‘브랜드 관리자’ 승인
알림톡을 받고 관리를 시작하세요.
※ 등록 후 영업일 기준 1~2일 내 처리 완료
CASE 2

내 브랜드가 검색되지 않는 경우

브랜드 셀프 등록 (무료 서비스)

기업회원 가입 → 창업도 메인 화면 우측 [브랜드 무료등록] 클릭 → 내 브랜드 등록 (관리자 승인 후 관리자 지정, 알림톡 발송)

알림톡 확인 → 창업도 로그인 → 브랜드관리자 클릭 → 내 브랜드 검색 → 좌측 대시보드 [브랜드관리 상세내용] 클릭 후 수정

브랜드 소개, 상단 이미지(창업도 노출 이미지), 홍보영상 URL, 브랜드 경쟁력, 프로모션 등을 직접 게재할 수 있습니다.

창업도에서 내 브랜드를 더 많이 노출하는 방법

창업도 멤버십 가입 안내 (유료)

추천 대상 · 프랜차이즈 가맹사업을 본격적으로 시작했거나, 내 브랜드를 적극적으로 알리고 싶은 프랜차이즈 본사

  • 창업도 배너광고 15일 무료 (50만원 상당)
  • 창업도 추천브랜드 100 노출 (최상단 카테고리)
  • 창업도 사이트 내 브랜드 페이지 셀프관리 권한 제공 (브랜드 소개, 특장점, 메뉴사진, 프로모션, 영상까지 자유롭게 등록)
  • 브랜드 페이지에서 ‘전화상담’ 문의 시 담당자 바로 연결
  • 창업도를 통한 가맹 문의 연결 (멤버십 [프리미엄] 가입 시)
